# 🐍 Python Learning Notebooks
 
A collection of Jupyter notebooks I created while learning Python from scratch. Each notebook focuses on one core topic and is packed with small, hands-on practice problems, from basic data types to user-defined functions.

## 📚 Contents
 
| # | Notebook | Topic | What's inside |
|---|----------|-------|---------------|
| 1 | `all data type and methods.ipynb` | Data types & methods | Variables, `int`, `float`, `str`, `bool`, arithmetic operators, and key methods of lists, tuples, sets and dictionaries |
| 2 | `indexing,slicing,stepping.ipynb` | Indexing & slicing | Positive/negative indexing, nested indexing, slicing, stepping, reversing, and challenge questions |
| 3 | `if-elsecondition.ipynb` | `if-else` | Positive/negative, even/odd, voting eligibility, pass/fail, comparing numbers |
| 4 | `elif-conditions.ipynb` | `elif` | Grade calculator, traffic light, number classification, age groups, discount logic |
| 5 | `different-elif.ipynb` | `elif` (practice) | Slab-based discount and final price calculators, largest of three numbers |
| 6 | `nested-if-else1.ipynb` | Nested `if-else` | Triangle type checker (equilateral / isosceles / scalene), positive/negative even/odd |
| 7 | `for-loop.ipynb` | `for` loop | Counting, tables, even/odd series, FizzBuzz, sum, count and average programs |
| 8 | `while-loop.ipynb` | `while` loop | Same problem set as `for` loops, solved with `while`, to compare both approaches |
| 9 | `Bulit-in-function.ipynb` | Built-in functions | `print`, `type`, `len`, `input`, `int`, `float`, `str`, `max`, `min`, `sum`, `abs`, `round`, `sorted`, `range`, `enumerate` |
| 10 | `User Difined.ipynb` | User-defined functions | 21 problems across four levels: basics, mathematical functions, logic functions and real-life problems (BMI, bill, simple interest, calculator) |
| 11 | `parameter.ipynb` | Parameters vs arguments | Positional arguments, positional-only (`/`) and variable-length (`*args`) arguments |
 
---
 
## 🧠 Concepts Covered
 
- **Fundamentals:** variables, data types, operators, type conversion
- **Collections:** lists, tuples, sets, dictionaries and their common methods
- **Strings & sequences:** indexing, slicing, stepping
- **Control flow:** `if`, `if-else`, `elif`, nested conditions
- **Loops:** `for`, `while`, `range()`
- **Functions:** built-in functions, `def`, parameters, arguments, return of results

## 🚀 Getting Started
 
### Prerequisites
 
- Python 3.8 or higher
- Jupyter Notebook or JupyterLab
### Installation
 
```bash
# Clone the repository
git clone https://github.com/<your-username>/<your-repo-name>.git
cd <your-repo-name>
 
# (Optional) create a virtual environment
python -m venv venv
source venv/bin/activate        # On Windows: venv\Scripts\activate
 
# Install Jupyter
pip install notebook
```
 
### Run
 
```bash
jupyter notebook
```
 
Then open any `.ipynb` file from the browser window that appears.
